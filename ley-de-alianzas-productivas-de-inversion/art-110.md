Artículo 110. Cuando, habiendo realizado la búsqueda de prospectos para la ejecución de un proyecto que demande el uso de componentes clave, no se encuentre ninguno con aptitud o solvencia para llevarlo a cabo, la entidad pública reconocida como tramitadora podrá abocarse a la estructuración de un grupo de agentes privados con capacidad de asumir conjuntamente la ejecución del proyecto con un nivel de confiabilidad aceptable.
